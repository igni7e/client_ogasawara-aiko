# おがさわら愛子 公式サイト（LP）

参政党 中野区政改革委員・おがさわら愛子の公式ランディングページ。静的HTML / CSS で構築。

## 構成

```
.
├── index.html        # ページ本体
├── css/
│   └── style.css     # スタイル（デザイントークン + レスポンシブ）
└── images/           # 画像アセット（人物写真・ロゴ・QRコード）
```

## プレビュー

GitHub Pages で公開しています（`main` ブランチのルートを配信）。

## 公開前に設定する項目

- 正式ドメイン
- プライバシーポリシー
- `<meta name="robots" content="noindex, nofollow">` の削除（正式公開時）

## 開発

ビルド不要。`index.html` をブラウザで開くか、任意の静的サーバーで配信してください。
